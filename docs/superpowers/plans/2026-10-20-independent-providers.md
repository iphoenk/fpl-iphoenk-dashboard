# Independent provider migration

Approved user scope: migrate only parts used from FPLens, FPL Insights, FPL Core and FPL Jakarta to prevent upstream repository loss. Existing UI, strategy and awards algorithms are already authored in this repository. Do not copy unlicensed code or claim retrained replicas of external engines.

Vercel adapter will own a private Blob mirror of used provider responses, with integrity digest, fetch timestamp, source and a strict endpoint allowlist. Official FPL remains authoritative. FPLens manifest+players must be acquired, validated and cached as one current-GW bundle. If provider and current valid mirror fail, serve explicitly labelled Official ep_next fallback, never call it FPLens/config_d or invent model features. Other analytics use last successful mirrored response preserving original timestamps; browser gates still hide wrong GW/season. Optional unavailable data is explicit, not zero. FPL Core computed evidence is mirrored; source snapshot identity validation stays. Jakarta awards code is already independent.

Tests simulate upstream loss, cold storage, corrupt/wrong-GW mirror, official fallback, disallowed routes and storage errors. Warm the private mirror from currently available used endpoints, verify metadata and failure behavior before rollout. No data or credentials in Git, no engine scheduler changes. Rollback baseline phase3 deployment dpl_Gocs3vTK1L7E4eYCEssd3nM5u5ZS, source25859456e4f09412a0e7409de8a13b6f5b3ff24d.

Undated legacy alternate predictions/optimizer/multi-GW files are retained only as unverified raw provider archives in private storage, not interpreted as current recommendations. Their source cannot prove a target GW; giving them the current Official manifest would be incorrect. Historical diagnostics and accuracy keep their declared source season/GW. Only default model bundle verified against current deadline/identity is offered in the picker. Fallback uses Official ep_next; no external model weights/retraining pipeline has been copied.
